
# Lamport Logical Clock Simulator

## Subject
CS3551 - Distributed Computing

## Project Topic
Develop a Lamport Logical Clock Simulator for Multiple Distributed Processes and Demonstrate the Ordering of Events.

## Description
This project demonstrates Lamport Logical Clocks
in a distributed computing environment.

It simulates multiple processes and assigns logical
timestamps to local, send, and receive events.

## Technologies Used
- Java
- Object-Oriented Programming

## Features
- Multiple distributed processes (P1, P2, P3)
- Local event simulation
- Message sending and receiving
- Logical timestamp calculation
- Event ordering
- Final clock display

## How to Run

Compile:
javac LamportLogicalClock.java

Execute:
java LamportLogicalClock
